## 1. Visual Theme & Brand Concept: "Warm Modern Leverage"

`asym.app` is the prelaunch product website for **Asymmetric.al**, an independent, for-profit software company building open-source giving, receipting, and supporter-care software built first for missions agencies where staff raise designated support, and designed cleanly for any donor-supported nonprofit.

Named for **asymmetric leverage** (helping a small office serve a large mission with care, without adding software drag or vendor lock-in), `asym` runs on **Core** (`Asymmetric-al/core`, `AGPL-3.0-only`), uniting three dedicated workspaces (`Donor portal` in `apps/donor`, `Missionary workspace` in `apps/missionary`, and `Mission Control` in `apps/admin`) on shared giving tables with server-enforced donor privacy. Next, we are designing practical AI for routine care work on top of the same open permissions (`AI drafts; people send.`). Public worker directories in `apps/donor` still use `@asym/mock-data` sample profiles; offline persistence (`501`), hosted teams, and AI tools are in development.

The website is **warm, human, modern, clean, and clear** — avoiding both 19th-century printshop nostalgia AND cold techno wireframes/cyberpunk glows, with **zero fake product UI, zero fictional donor records, and zero em dashes in public website copy**:

- **Warm sculptural visual language (`components/site/home/asymmetric-field.tsx`) + Core Screens Gallery (`public/captures/`):**
  - **Hero Sculpture (`AsymmetricFieldHero`):** Matte overlapping sage, warm sand, terracotta, and deep botanical curved planes derived directly from `asym`'s official mark geometry (`mark-geometry.ts`) inside a generous Maia `rounded-[26px]` frame — tactile and sunlit rather than wireframe or CAD. Zero raster image requests; adapts instantaneously to Light, Dark, and Forced Colors via CSS custom properties.
  - **Core Screens Gallery (`ScreensGallery` in `components/site/reactbits/screens-gallery.tsx`):** Adapted from React Bits Pro `Gallery3` (`8/4` widescreen stage + 2×2 thumbnail picker) and `Gallery2` (`01 / 04` counter & Prev/Next controls) with `@ui-sdk/react/tabs` and `BrowserWindow` (`components/site/reactbits/browser-window.tsx`), displaying all four cropped `16:9` widescreen captures from `Asymmetric-al/core` (`web-studio.png`, `donor-portal.png`, `public-website.png`, `missionary-updates.png`) with zero magnifier overlay, exact-height zero-CLS SSR fallback, `<noscript>` full-set fallback, `Sample content` badge, and explicit Give Hope demo-tenant provenance.
  - **Vision Grounded-AI Pipeline (`Pipeline` in `components/site/reactbits/pipeline.tsx`):** Adapted React Bits Pro workflow graph on flat Deep Botanical Pine (`#1e2925`) inside a soft `rounded-[24px]` frame — five concrete missions-workflow nodes (`Gift arrives` + `Privacy checked` -> `Thank-you draft` -> branching to `You send it` in Warm Dusty Terracotta and `Care logged` in Soft Eucalyptus Sage) with calm hover connection highlighting, settled static state under `prefers-reduced-motion: reduce`, and zero-CLS static SSR/no-JS fallback.
  - **Tactile Maia Surfaces (`SpotlightCard` in `components/site/reactbits/spotlight-card.tsx`):** Adapted zero-dependency React Bits pointer-illuminated surface sheen (`6%`–`7.5%` `--signal` / `--human` radial tint, fine-pointer & `:focus-visible` only, zero frosted glass, zero inline JSX styles) applied sparingly to workspace outcome cards and the 2×2 stewardship grid.
  - **Perspective Facets (`PerspectiveFacet`):** Compact warm-mist `rounded-2xl` icon wells with minimal organic `asym` facets anchoring the three workspace outcome cards.
- **Calm, earthy four-ink semantic system:**
  - **Botanical Eucalyptus Sage (`--signal`, `--ring`)** (`#265f48` light / `#8fc9a9` dark) encodes verified public open-source code (`In code` / `Partial`), active focus rings, and calm sentence-case section eyebrows.
  - **Warm Dusty Terracotta (`--human`, `--primary`)** (`#ae4e35` light / `#d3876b` dark) encodes primary Header/Hero actions, warm human highlights, and live early-access intake. Secondary/utility dark buttons (such as status-page recovery actions) use solid **Warm Charcoal (`variant: "ink"`)**.
  - **Warm Slate (`--draft`, `border-dashed`)** encodes AI capabilities and hosted/roadmap plans currently in development.
  - **Deep Rose (`--destructive` / `--destructive-border`)** is decoupled for form validation errors and alerts, always paired with an explicit error icon.
- **Soft Shadcn Maia solid surfaces (zero frosted glass, zero harsh noise grain):** Every header (`bg-background`), card (`bg-card`), recessed block (`bg-record`), and popover uses clean, silky solid stock with generous `base-maia` curvature (`rounded-[26px]` / `rounded-[24px]` sculptural frames, `rounded-2xl` outcome cards, ledger, decision tray, founders card, & early-access close, `rounded-full` buttons, pill inputs, segmented tracks, status chips, & circular monogram avatars, `rounded-2xl` textareas).

## 3. Typography Rules

- **Display (`font-heading`):** **Plus Jakarta Sans** (`500`, `600`, `700`, preloaded) — warm, open, human modern geometric sans. Hero H1: `clamp(2.2rem, 4.7vw, 4.15rem)`, `leading-[1.03]`, `-0.035em`. Section H2: `clamp(2rem, 3.8vw, 3.15rem)`, `leading-[1.06]`, `-0.03em`.
- **UI & Body (`font-sans`):** **Instrument Sans** (`400`, `500`, `600`, preloaded) for body prose, calm sentence-case section eyebrows, card role labels, and founder provenance facts.
- **Code & Status Metadata (`font-mono`):** **Geist Mono** (`400`, `500`, `preload: false` swap) reserved cleanly for real repository paths, pill status badges, local evaluation commands, and commit/PR counts.
- **No-hyphen prose & zero em dashes:** Normal prose preserves `hyphens: none`, `overflow-wrap: normal`, `word-break: normal`, minimum `12px` (`text-xs`), and avoids em dashes across public website copy.

## 5. Motion, Accessibility & Technical Floor

- **Compositor-only motion & unified easing:** All UI transitions share one strong ease-out token (`--ease-out: cubic-bezier(0.23, 1, 0.32, 1)`). `.segmented-indicator` (`ThemeToggle`, `PrivacyMatrix`, `Cta17`, & `StatusLedger` filter) animates `transform` only (`180ms`, suppressed on first paint via `[data-activation-direction="none"]`) with consistent `font-medium` weights across active/inactive navigation and segmented items (`0px` horizontal text reflow); `MobileNavMenu` uses asymmetric enter/exit timing (`180ms` enter / `110ms` exit from `origin-(--transform-origin)`); `QuickJumpPalette` opens/closes instantaneously with keyboard `scrollIntoView({ block: "nearest" })` and clear-search recovery; `.sculpt-reveal` (`620ms` gentle rise), `.surface-enter` (`140ms`), tactile `active:scale-[0.97]` press feedback, fine-pointer guarded `:hover`, and full `@media (prefers-reduced-motion: reduce)` collapse.
- **Accessibility, Security & CI checks:** Automated axe-core audits across light, dark, interactive, default-motion, mobile menu, and configured form states (`0` violations), token-checked contrast (`lib/theme-contrast.test.ts`), direct Vitest route-handler tests (`lib/early-access-route.test.ts`), `canonical: null` on all `noIndex` routes, Forced Colors high-contrast selection & focus rules, `>= 44px` mobile targets, `16px` mobile inputs preventing Safari auto-zoom, safe-area footer inset, `0` inert non-submit buttons without JS, static document & API Content-Security-Policy (`object-src 'none'`, `frame-ancestors 'none'`) via `next.config.ts` compatible with Next.js 16 `cacheComponents`, HSTS preload, COOP `same-origin`, full-origin CSRF, rate-limiter, anti-spoof cookie, and CI enforcing full `bun run lint` (`0` errors), Stylelint, TypeScript, Vitest, and dual-mode (`:3100` + `:3101`) Playwright suites.
